🎯 Цель

Исправить мобильную верстку EarnIt Kids: safe-area, шапка, отступы, переполнение, кликабельность, чтобы ничего не обрезалось и не перекрывалось (особенно сверху и снизу).

⸻

P0 (срочно) 🚨 Блокирующие проблемы

1) Safe-area и фиксированная шапка (iOS notch) 📱 ✅

Проблема по скринам: верхний контент/заголовки и счетчик монет визуально “прилипают” к верху, местами обрезаются.
Задачи:
•	Добавить safe-area отступы для верхней панели и основного контента:
•	padding-top: env(safe-area-inset-top) для header
•	padding-bottom: env(safe-area-inset-bottom) для bottom-nav/страницы
•	Проверить meta viewport (нет ли user-scalable=no и странных width).
•	Если header position: fixed/sticky, гарантировать content отступ сверху равный реальной высоте header.

Acceptance criteria ✅
•	На iPhone с notch (и без) шапка не обрезается, контент начинается строго под шапкой.

⸻

2) Нижняя навигация перекрывает контент ⬇️ ✅

Проблема по скринам: нижний бар/кнопки могут залезать на карточки (особенно “Уровень Lv 1” и нижние элементы).
Задачи:
•	Для страниц с bottom-nav добавить “нижний отступ под навбар”:
•	padding-bottom: calc(var(--bottom-nav-height) + env(safe-area-inset-bottom))
•	Убедиться, что bottom-nav имеет стабильную высоту (CSS переменная) и не “прыгает” от контента.

Acceptance criteria ✅
•	Последняя карточка/строка всегда полностью видна и не закрыта bottom-nav.

⸻

3) Обрезается/наезжает заголовок секции (например “Прогресс…”) ✂️ ✅

Проблема по скрину: текст заголовка секции визуально режется слева/сверху.
Задачи:
•	Проверить контейнер заголовка: нет ли отрицательных margin, overflow: hidden, или неправильной высоты строки.
•	Нормализовать типографику:
•	line-height: 1.2-1.4
•	padding вместо “магических” top:-x
•	Прогнать через разные масштабы текста (iOS Dynamic Type / Android font scale).

Acceptance criteria ✅
•	Заголовки никогда не обрезаются при scale 100–130%.

⸻

P1 (важно) ⚙️ UX/адаптивность

4) Управление шириной кнопок и карточек (не должно “распухать”) 🧩 ✅

Проблема по скрину: большие кнопки (“Просмотреть заявки”) занимают почти всю ширину карточки, возможны артефакты с внутренними отступами/скруглением.
Задачи:
•	Ввести единые правила для кнопок:
•	min-height (tap target 44–48px)
•	width: 100% только внутри форм/CTA-зон
•	ограничить max-width для больших экранов
•	Карточки: проверить padding, gap, border-radius на узких ширинах.

Acceptance criteria ✅
•	CTA-кнопки выглядят одинаково на ширине 320/360/390/430px.

⸻

5) Переполнение текста и переносы (русский длиннее) 🧾 ✅

Задачи:
•	Для строк с числами/лейблами (“2 заявки”, “Ожидают решения…”) добавить:
•	overflow-wrap: anywhere или аккуратно word-break
•	для вторичных текстов: line-clamp на 2 строки
•	Для бейджей справа (“1/день”) обеспечить фикс ширину/минимум и запрет перекрытий:
•	flex: 0 0 auto для бейджа
•	текст слева min-width: 0 + ellipsis

Acceptance criteria ✅
•	Ничего не выезжает за границы карточек, не перекрывает бейджи.

⸻

6) Z-index и плавающие элементы (кнопка переводчика/виджеты) 🧷 ✅

Проблема по скринам: плавающая круглая кнопка сбоку перекрывает контент.
Задачи:
•	Определить слойность: header, bottom-nav, fab, modal, toast.
•	Для FAB:
•	сместить выше bottom-nav
•	сделать “умное” позиционирование (не перекрывать важные CTA)
•	добавить pointer-events правила для декоративных слоев

Acceptance criteria ✅
•	FAB не закрывает важные кнопки/тексты, не мешает скроллу.

Acceptance criteria ✅
•	Нет “уникальных” отступов на отдельных страницах, которые ломают мобильную верстку.
