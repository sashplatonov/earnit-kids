Уведомлять при изменении количества монет
Не делать: круглый control размером почти с иконку, где положение on/off читается только по белому кружку. Такой элемент похож на плавающую кнопку, а не на стандартный switch.
Ключевой UX: визуальный switch должен быть компактным, примерно 44×26 px, с понятным горизонтальным track и thumb. Состояние должно считываться мгновенно: серый track = off, accent track = on. Сам control не должен конкурировать по размеру с иконкой уведомления.
