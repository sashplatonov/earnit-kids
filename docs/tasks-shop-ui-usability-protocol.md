# Tasks and shop usability protocol

This is the manual validation plan for TSU-011. It is intentionally separate from production telemetry: no child names, task text, notes, cues, or direct identifiers are collected.

## Sessions

Run five moderated sessions across ages 7–9, 10–12, and 13–15, with a parent/admin representative in at least two sessions. Use a disposable family and reset data after each session.

## Tasks

1. Find a task, submit it once, and explain the pending/success/error state.
2. Buy/request a shop reward and identify the remaining balance.
3. Set a reward goal, return to Tasks, and explain progress toward it.
4. Create an optional “if–then” cue and find it on the task card.
5. Repeat on a 360px viewport with large text and reduced motion enabled.

## Success criteria

- 4/5 participants complete each flow without moderator intervention.
- No duplicate request is created after a double click.
- Participants can recover from a simulated rejection using Retry.
- Card titles, controls, and chips remain readable with no overlap or clipping.
- At least 4/5 participants can describe what to do next from the Today summary.

Record only aggregate task outcome, age band, viewport class, and accessibility setting. Do not record names, free text, notes, cue content, or screenshots containing personal data.
